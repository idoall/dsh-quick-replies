适配 DeepSeek Harness `0.2.0-rc.1`：逐项核对全部消费契约后确认零破坏，代码零改动，升级无需迁移。peer 范围显式声明 `0.2` 线。

| --- | --- | --- |
| **`0.1.7`** | **`0.2.0-rc.1`（最新）**、`0.1.7-rc.2`、`0.1.7-rc.1`、`0.1.7-alpha.2` | 本次发布（`latest`） |

### 为什么发这个版本

旧范围 `>=0.1.7-alpha.2 <0.2.0` 在 node-semver 默认预发布规则下并不接纳 `0.2.0-rc.1`（此前 DSH 门禁放行只因 `includePrerelease: true`）——声明与事实不符。

### ⚠️ 变更

- peer 与 `dsh.engines.dsh` 范围改为 `>=0.1.7-alpha.2 <0.2.0-0 || 0.2.0-rc.1 || >=0.2.0 <0.3.0`：已验证的 `0.1.7` 线、精确钉死的 `0.2.0-rc.1`（没人测过的 `rc.2` 进不来）、到 `<0.3.0` 为止的 `0.2.0` 正式版线。
- `dshReleases` 记录 `0.2.0-rc.1`；devDep 的 `@deepseek-ai/dsh-settings` 钉到 `0.2.0-rc.1`；两份 README 同步。

### ✅ 核对与实测

- 0.2.0-rc.1 源码逐项核对：`conversation.input.dock` 插槽、客户端静态模块表（9 个平台模块）、`__ModuleLoader__` 注册协议、`ctx.configForms`、`settings/document-updated`、`prompt(content, mode)` 全部未变。
- typecheck 直接针对 `0.2.0-rc.1` 通过；98 项测试全绿（含按 harness 方式装载 `lib/` 产物的 lane）。
- 运行中的 0.2.0-rc.1 实例实测：`dsh --profile web --dump-config` 正常装载、无 skipping 警告，条目 `config` 完整呈现。

### 升级

```sh
dsh plugin --profile web add dsh-quick-replies@0.1.7
```

回复库无需迁移、配置无需改动；升级后**重启 `dsh web`**，客户端半边刷新页面即生效。

### Why this release exists

The old range `>=0.1.7-alpha.2 <0.2.0` did **not** admit `0.2.0-rc.1` under node-semver's default prerelease rule — the DSH gate passed it only because it checks with `includePrerelease: true`. The declaration no longer matched the fact.

### ⚠️ Changes

- The peer and `dsh.engines.dsh` ranges become `>=0.1.7-alpha.2 <0.2.0-0 || 0.2.0-rc.1 || >=0.2.0 <0.3.0`: the verified `0.1.7` line, `0.2.0-rc.1` pinned exactly (an untested `rc.2` stays out), and the stable `0.2.0` line up to `<0.3.0`.
- `dshReleases` records `0.2.0-rc.1`; the pinned `@deepseek-ai/dsh-settings` devDependency moves to `0.2.0-rc.1`; both READMEs updated.

### ✅ Verified

- Item-by-item check against the 0.2.0-rc.1 source: the `conversation.input.dock` slot, the client static module table (nine platform modules), the `__ModuleLoader__` registration protocol, `ctx.configForms`, `settings/document-updated` and `prompt(content, mode)` are all unchanged.
- Typecheck runs directly against `0.2.0-rc.1` and passes; all 98 tests green (including the artifact lane that loads `lib/` the way the harness does).
- Measured on the running 0.2.0-rc.1 instance: `dsh --profile web --dump-config` loads the entry with no skipping warning, and the entry `config` renders in full.

### Upgrade

```sh
dsh plugin --profile web add dsh-quick-replies@0.1.7
```

No data migration, no config change; **restart `dsh web`** after upgrading — the client half takes effect on page refresh.
