插件 `0.1.19`：支持 DSH `0.2.2-alpha.3`（alpha）与 `0.2.1-rc.5`（latest/next）。

<h3 id="cn-v0.1.19">兼容性与发布检查</h3>

- **同步最新支持版本。** 将两个版本显式加入 DSH engine、settings peer 和兼容矩阵，保留此前支持版本；不改变回复库、发送行为或用户配置，无需数据迁移。
- **核验官方接口。** 对比六个直接使用的官方包：`0.2.1-rc.4` → `0.2.1-rc.5` 仅包元数据变化；`0.2.2-alpha.2` → `0.2.2-alpha.3` 保留本插件使用的会话发送、输入槽位、输入阶段和设置接口，无需修改产品代码。
- **对齐开发依赖。** settings 钉到 `0.2.2-alpha.3`，Cordis / Schemastery 更新至 `4.0.6-alpha.2` / `3.18.6-alpha.2`，并对齐 include / group 的开发期 peer 依赖。
- **避免漏测发布包。** CI、Release 与本地 verify 改为先构建再测试，确保构建产物测试不会在干净环境被跳过；新增版本、双语文档和发布流程一致性检查。
- **文档同步。** 中英文 README、更新记录、Release 与 npm manifest 使用一致版本，并说明 DSH `0.2.2-alpha.3` 要求 Node.js **24.9.0+**（插件自身的 Node.js 20 下限不代表宿主要求）。
- **验证范围。** 覆盖官方包接口、类型检查、单元/UI 测试和构建产物；真实浏览器交互未验证：GUI 返回 HTTP 401，Client Inspect 未暴露该槽位。未修改 profile 配置或其他工作区插件。

### 升级

```sh
dsh plugin --profile web add dsh-quick-replies@0.1.19
```

升级后重启 `dsh web` 并刷新页面。

Plugin `0.1.19`: supports DSH `0.2.2-alpha.3` (alpha) and `0.2.1-rc.5` (latest/next).

<h3 id="en-v0.1.19">Compatibility and release checks</h3>

- **Synchronize supported versions.** Add both versions explicitly to the DSH engine, settings peer range and compatibility matrix, retaining earlier supported releases. Reply storage, sending behavior and user configuration are unchanged; no migration is needed.
- **Verify official interfaces.** Compare the six directly consumed official packages: `0.2.1-rc.4` → `0.2.1-rc.5` changes package metadata only; `0.2.2-alpha.2` → `0.2.2-alpha.3` preserves the session prompt, input dock, input phase and settings interfaces used here. No product code change is required.
- **Align development dependencies.** Pin settings to `0.2.2-alpha.3`, update Cordis / Schemastery to `4.0.6-alpha.2` / `3.18.6-alpha.2`, and align the include / group development peer dependencies.
- **Test the actual build.** CI, Release and local verify now build before testing so artifact tests are not skipped on a clean checkout. Add consistency checks for versions, bilingual documentation and release ordering.
- **Synchronize documentation.** Both READMEs, changelog, Release and npm manifest use consistent versions. Document that DSH `0.2.2-alpha.3` requires Node.js **24.9.0+**; the plugin's own Node.js 20 minimum does not replace the host requirement.
- **Verification scope.** Official package contracts, typechecks, unit/UI tests and built artifacts are covered. Live browser interaction is unverified: the GUI returned HTTP 401 and Client Inspect did not expose the dock. No profile configuration or other workspace plugin was changed.
