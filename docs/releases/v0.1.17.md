[中文](#cn-v0.1.17) | [English](#en-v0.1.17)

Adds support for DSH `0.2.1-rc.4` without changing quick-reply behavior.

Supports DSH `0.2.1-rc.4`, while retaining compatibility with `0.2.1-rc.3` and previously declared releases.

<h3 id="en-v0.1.17">⚠️ Changed</h3>

- **Declare support for the latest candidate.** `0.2.1-rc.4` is added to `dsh.engines.dsh`, the `@deepseek-ai/dsh-settings` peer range and the compatibility matrix; earlier releases were only admitted by the installer's prerelease leniency, and now the default semver rules accept it too.
- **Package-by-package check found no breaking change.** Five of the six directly consumed official packages differ only in their manifest; `dsh-client-ui-conversation` only drops one locale key and adds an overflow tooltip to View labels, leaving the slot and composer interfaces used here untouched.
- **No migration required.** Sending logic, the reply library and fold preferences are unchanged; the built artifacts are byte-identical to `0.1.16`.

### Upgrade

```sh
dsh plugin --profile web add dsh-quick-replies@latest
```

Restart `dsh web` afterwards and refresh the page.
