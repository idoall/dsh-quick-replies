插件 `0.1.20`：支持 DSH `0.2.2-rc.1`（npm `next`）。继续支持 `0.2.2-alpha.3`（`alpha`）、`0.2.1-rc.5`（`latest`）及此前已声明版本。

<h3 id="cn-v0.1.20">兼容性更新</h3>

- **显式支持新 RC。** 在 DSH engine、settings peer 与兼容矩阵中加入 `0.2.2-rc.1`，严格 semver 和 DSH 自身兼容门禁均接纳；`0.3.0` 仍不在支持范围内。
- **对齐新版宿主依赖。** settings 开发依赖更新为 `0.2.2-rc.1`，Cordis 为 `4.1.0`、Schemastery 为 `3.19.0`，include / group 为 `1.1.0`；现有 Cordis / Schemastery peer 范围已覆盖这些正式版本，无需收窄旧版支持。
- **文档与发布检查同步。** 中英文 README、更新记录、Release 与 npm manifest 同步插件和 DSH 版本；修正两份 README 开发命令为先构建再测试，并加入回归检查。当前 DSH 仍要求 Node.js **24.9.0+**。
- **无需改动产品代码。** 六个直接使用的官方包从 alpha.3 到 rc.1 仅包元数据变化，运行代码、类型声明和文档逐字节相同。回复库、快捷发送与用户配置保持不变，无需数据迁移。
- **验证边界。** 检查官方包接口、类型、单元/UI 测试和构建产物。GUI 返回 HTTP 401，Client Inspect 未暴露输入槽位，未验证真实页面点击发送；未修改 profile 或其他工作区插件。

### 升级

```sh
dsh plugin --profile web add dsh-quick-replies@0.1.20
```

升级后重启 `dsh web` 并刷新页面。

Plugin `0.1.20`: supports DSH `0.2.2-rc.1` (npm `next`). Retains support for `0.2.2-alpha.3` (`alpha`), `0.2.1-rc.5` (`latest`) and previously declared releases.

<h3 id="en-v0.1.20">Compatibility update</h3>

- **Explicit support for the new RC.** Add `0.2.2-rc.1` to the DSH engine, settings peer range and compatibility matrix. Both strict semver and DSH's compatibility gate admit it; `0.3.0` remains unsupported.
- **Align host development dependencies.** Update settings to `0.2.2-rc.1`, Cordis to `4.1.0`, Schemastery to `3.19.0`, and include / group to `1.1.0`. Existing Cordis / Schemastery peer ranges already cover these stable releases without dropping older support.
- **Synchronize documentation and release checks.** Both READMEs, changelog, Release and npm manifest agree on the plugin and DSH versions. Correct the README development commands to build before testing and add a regression check. Current DSH still requires Node.js **24.9.0+**.
- **No product code changes needed.** The six directly consumed official packages differ from alpha.3 only in package metadata; runtime code, declarations and documentation are byte-identical. Reply storage, quick sending and user configuration are unchanged; no migration is needed.
- **Verification limits.** Official package contracts, types, unit/UI tests and built artifacts are checked. The GUI returned HTTP 401 and Client Inspect did not expose the input dock, so real-page sending was not verified. No profile or other workspace plugin was modified.

### Upgrade

